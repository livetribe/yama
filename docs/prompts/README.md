# Prompt Archive

This directory is a non-authoritative archive of prompts used to start earlier
chat sessions.

Do not use the files in this directory as requirements, design guidance,
architecture guidance, implementation instructions, coding-agent context, or
source material for future code changes.

For project direction, use the actual project documents instead:

* `docs/PRD.md`
* `docs/adr/`
* source code and tests

The prompt files are kept only for historical reference and may be incomplete,
stale, speculative, or inconsistent with the current repository state.

## Contents

* `prd.md` - prompt used to generate ADRs and PRD
* `architecture.md` - prompt used to generate architecture
